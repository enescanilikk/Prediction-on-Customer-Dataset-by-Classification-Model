# Prediction-on-Customer-Dataset-by-Classification-Model

A machine learning classification pipeline designed to predict whether a customer is likely to purchase an electric vehicle (`Will_Buy_EV`) based on demographic attributes, current vehicle profile, infrastructure availability, and behavioral factors.

## Overview

Predicting consumer adoption of Electric Vehicles (EVs) helps manufacturers, charging infrastructure providers, and policy makers optimize targeting and subsidy programs. This project builds an end-to-end classification and probability estimation pipeline utilizing gradient boosting models.

### Target Variable
* `Will_Buy_EV`: Binary classification (`yes` / `no`).

### Key Features
* **Demographics & Geography:** `Gender`, `City_Type`
* **Vehicle & Charging Profile:** `Current_Car_Type`, `Home_Charging_Possible`
* **Incentives & Consumer Sentiment:** `Subsidy_Available`, `Range_Anxiety_Level`
